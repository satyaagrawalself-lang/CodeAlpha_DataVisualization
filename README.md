# Data Visualization on Book Dataset

## Project Overview

This project focuses on visualizing book data collected through web scraping. Various charts and graphs were created to understand the distribution of book prices and ratings, making the data easier to interpret and analyze.

## Tools and Technologies Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset Information

The dataset contains:

* Book Title
* Price
* Rating

## Visualizations Created

1. Distribution of Book Prices (Histogram)
2. Book Rating Distribution (Bar Chart)
3. Top 10 Most Expensive Books (Bar Chart)
4. Percentage Distribution of Ratings (Pie Chart)

## Key Findings

* Book prices vary across different ranges.
* One-star rated books are the most common category.
* A few books have significantly higher prices than others.
* Visual representations make it easier to identify trends and patterns in the dataset.

## Conclusion

Data visualization helps transform raw data into meaningful insights. The charts created in this project provide a clear understanding of book pricing and rating patterns, supporting better data interpretation and decision-making.
